# IBM 1401 and IBM 729 project scope

## Components in this repository
- Character-addressed storage with a word-mark bit.
- A preliminary CPU step interface and a mnemonic orientation table.
- A virtual tape-image format with records and tape marks.
- Named IBM 729 tape-drive profiles using the common virtual tape backend.
- Text card-deck and line-printer abstractions.

## Important limits
The current IBM 1401 CPU stepper does not execute instructions yet. The opcode table is a study aid, not a verified decode table. Character encoding is not a complete 1401 BCD code. The virtual tape model does not yet simulate tape motion, inter-record gaps, density-specific data encoding, parity, rewind time, or physical transport behavior.

## Suggested validation sequence
1. Transcribe instruction formats from the IBM 1401 reference manual.
2. Implement address-field parsing and word-mark-aware instruction boundaries.
3. Add arithmetic and compare semantics with condition and mark behavior.
4. Add read/write device operations and verify with tiny programs.
5. Compare tests against published manual examples and a trusted emulator.
