# IBM System/360 and IBM 2400 project scope

## Components in this repository
- Byte-addressed storage and 16 general-purpose registers.
- A small RR instruction subset (BALR, BCR, LR and AR).
- Metadata for supported instruction encodings.
- A simple channel command queue abstraction.
- Named IBM 2400-family drive profiles backed by the virtual tape image.

## Important limits
This is not a complete System/360 CPU or channel subsystem. Instruction execution, condition-code edge cases, interruption processing, PSW formats, channel programs, sense data, device timing and model-specific device behavior remain incomplete. IBM 2400 profiles are labels/configuration values, not cycle-accurate models.

## Suggested validation sequence
1. Implement instruction formats and address generation from Principles of Operation.
2. Add program-status-word and interruption semantics.
3. Add channel command word chaining and I/O interruption flow.
4. Model device command/status/sense behavior for a chosen 2400 model.
5. Run regression programs with expected register, storage and device states.
