# Virtual hardware inventory

## IBM 1401 side
- Character-addressed memory model with separate word-mark bit
- Planned IBM 729 tape transport
- Virtual 80-column card deck and line printer abstractions

## System/360 side
- Byte-addressed storage, 16 general registers, instruction address and condition code
- Small educational register-instruction subset (LR, AR, BALR, BCR)
- Planned PSW, interruption handling, model-specific features, channel subsystem, and 2400-series nine-track tape

The drive classes are software simulations. They do not drive physical IBM equipment. Exact historical speeds and features vary by model.
