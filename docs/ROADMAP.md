# Roadmap

- [x] C++23/CMake skeleton
- [x] Virtual tape image, tape mark and record navigation
- [x] 1401 character storage and word-mark representation
- [x] System/360 byte storage and registers
- [x] Virtual tape drive, card deck and line printer abstractions
- [x] Initial System/360 register instruction subset
- [x] Experimental fixed-form FORTRAN reader/translator
- [ ] Full IBM 1401 instruction decoding and verified BCD semantics
- [ ] Broader System/360 instruction set, PSW, interrupts and addressing modes
- [ ] Accurate channel command and device status processing
- [ ] FORTRAN IV FORMAT, I/O, DO, labels, subprograms and runtime conventions
- [ ] Executable object-module generation and loader
- [ ] Regression tests against manuals and trusted emulators

This repository is an incremental educational emulator, not a complete IBM-compatible implementation.
